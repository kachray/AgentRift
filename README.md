# AgentRift

AgentRift is a pixel-art top-down world where five simulated AI agents walk between
stations and, when unresolved issues pile up past a threshold, gather at a meeting point
to hold a four-persona council debate generated by the Groq API. It is a Phaser 3 + Vite
client with an Express + WebSocket server and JSON file persistence — no database, no
frontend framework.

## Setup

```bash
git clone <repo-url>
cd agentrift
npm install
cp .env.example .env
```

Then edit `.env` and set `GROQ_API_KEY` to a real key from
[console.groq.com](https://console.groq.com). Never commit `.env`.

Run the two processes in separate terminals:

```bash
npm run dev:server   # Express + ws server on :3000 (hot reload)
npm run dev:client   # Vite dev server for the Phaser client on :5173
```

Open http://localhost:5173, file issues until the unresolved count crosses the threshold,
and watch the agents walk to the meeting point to debate.

## Architecture

The repo splits into `server/` (Express REST API + ws WebSocket bridge + the council
engine), `client/` (the Phaser game, bootstrapped from a single `index.html`), and
`shared/` (types and config used by both sides). Every state change — an agent moving, an
issue filed or resolved — flows through a store (`createAgentStore` / `createIssueStore`),
which persists to `server/data/*.json` and emits a change event; the WebSocket hub maps
those events to typed `WSEvent` messages and pushes them to the client, which animates the
sprites accordingly. When unresolved issues cross the threshold, a latched trigger sends
each agent to its own council seat, and the debate itself is generated persona-by-persona
with independent Groq API calls.

## Running tests

```bash
npm test   # Vitest, server-side logic; tests use temp dirs, never server/data/
```

## Known limitations

- **Placeholder art.** The tiles and sprites are placeholders, not the original paid
  tileset the project was designed around.
- **Simulated demo agents.** The five agents are scripted demos with no real Claude Code
  session hookup.
- **CORS is hardcoded to localhost.** `server/index.ts` allowlists only
  `http://localhost:5173`; this MUST change before any deployment off localhost.
- **Groq model id pinned via env var.** The council engine defaults to `openai/gpt-oss-120b`,
  overridable with `GROQ_MODEL` in `.env`, because Groq's free model catalog has changed
  before and retired models 404.
